# Rocketlane technology-stack research

This repository contains original analysis of publicly available information about Rocketlane's technology stack. Findings, confidence grades, and source links are in the three workstream reports and the consolidated reference.

The research was conducted passively using public sources. It did not involve signing in, using credentials, submitting forms, scanning ports, fuzzing, brute force, or load testing. The reports distinguish vendor statements, direct observations, third-party reporting, and inference.

Downloaded web pages, legal documents, public JavaScript bundles, and captured browser/evidence data are intentionally not included. The repository contains analysis and citations, not copies of those source materials.
